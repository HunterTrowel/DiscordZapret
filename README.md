> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
>
> Для работы zapret нужен WinDivert — инструмент перехвата и фильтрации трафика. Поэтому он может вызвать предупреждение антивируса.  
> WinDivert способен использоваться разными программами, включая вредоносные, однако сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусы классифицируют файлы WinDivert как потенциально опасные или относящиеся к хакерским инструментам, после чего удаляют их и отправляют в карантин. Название такого обнаружения обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше создать исключение; в противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Настройка и запуск

1. Активируйте безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS в настройках самой системы. [Инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/); этот вариант рекомендуется пользователям Windows 11.
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно.

2. Получите архив zip/rar со [страницы последнего релиза](https://github.com/HunterTrowel/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и отметьте "Разблокировать". Для архивов, открываемых через 7-Zip или PeaZip, этот шаг можно не выполнять.

4. Распакуйте архив в каталог, путь к которому не содержит кириллицу и специальные символы.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Для запуска стратегии вместе с системой выберите **`service.bat`** -> `Install Service` -> подходящую стратегию.

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — запускает выбранную стратегию вручную.

  Такой запуск удобен для проверки вариантов обхода. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую для себя**.

- [**`service.bat`**](./service.bat) — содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб.
  - **`Check Status`** — показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** — включает или отключает обход для игр и прочих сервисов, работающих с UDP и TCP на портах выше 1023.  
  После изменения параметра стратегию необходимо перезапустить.  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — меняет режим обработки сервисов из `ipset-all.txt`.  
  Этот пункт полезен при поиске причины, если ресурс без zapret работает, а с ним — нет.  
  В скобках показывается режим:
    - `none` — проверка IP не выполняется;
    - `loaded` — адрес проверяется на наличие в списке;
    - `any` — фильтруется любой IP.
  - **`Auto-Update Check`** — включает или выключает автоматический поиск обновлений.
  - **`Replace active fakes`** — заменяет текущий используемый fake на другой файл из `bin`.
  - **`Update IPSet List`** — загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** — обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовому чату Discord.</ins>
  - **`Check for Updates`** — вручную ищет обновления.
  - **`Run Diagnostics`** — проверяет распространённые причины неисправности zapret.  
  В финале можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения.
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — проверяет сайты, перечисленные в `utils/targets.txt`;
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️Частые вопросы и неисправности

### После запуска `general*` ничего не видно

При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/HunterTrowel/zapret-discord-youtube/issues/522).

### Рабочей стратегии нет

- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - скопируйте весь текст из открытого блокнота;
  - откройте файл `hosts` в созданной папке текстовым редактором, запущенным от имени администратора;
  - вставьте скопированное содержимое в конец `hosts` либо замените ранее добавленные аналогичные строки;
  - сохраните файл и проверьте соединение ещё раз. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работа не гарантируется. При отсутствии результата используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/HunterTrowel/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии со временем могут терять работоспособность.**
> После обнаружения конкретная стратегия, которая некоторое время работала, может перестать обходить блокировку.
> В репозитории есть разные варианты стратегий. Если ни один не подходит, создайте новый, взяв один из них за основу и изменив параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте вывод `service.bat` -> `Run Diagnostics` и устраните найденные ошибки.
- Убедитесь, что нужный адрес присутствует в доменных списках или списках IP.
- Проверьте варианты **`ALT`**, **`FAKE`** и другие стратегии.
- Выполните полную переустановку по инструкции ниже.
- Дополнительная информация есть в [#765](https://github.com/HunterTrowel/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?

- Сохраните добавленные вами ресурсы и данные.
- Перезапустите устройство.
- В `service.bat` выполните `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки и в конце подтвердите действие клавишей Y.
- Удалите каталог zapret.
- Загрузите актуальную версию [со страницы релизов](https://github.com/HunterTrowel/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу окна есть пункт разблокировки, отметьте его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новый каталог в корне диска, исключив пробелы, спецсимволы и кириллицу из пути.
- Запускайте разные скрипты `general` и проверяйте доступ к ресурсам. Если стратегия не подходит, закройте программу через значок замка на панели задач и попробуйте следующую.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение перестали работать с включённым zapret

- В `service.bat` проверьте, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` — **`none`**. Иначе обход может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Узнайте имя службы в командной строке Windows, открытой через Win+R -> `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fнастройка-и-запуск).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Переберите остальные стратегии, особенно если раньше доступ был, а затем исчез.
- Смотрите также [#251](https://github.com/HunterTrowel/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что включён [Secure DNS](#%EF%B8%8Fнастройка-и-запуск).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и очистите там кэш Discord.
- Проверьте приложение Discord после очистки кэша.
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если браузерная версия тоже недоступна, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- Дополнительные сведения: [#252](https://github.com/HunterTrowel/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Используйте [tg-ws-proxy](https://github.com/HunterTrowel/tg-ws-proxy).
- Либо выберите бесплатный MTProto-прокси из интернета.

### Не запускаются игры или нет подключения

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте универсальную последовательность:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/HunterTrowel/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Создайте описание проблемы [здесь](https://github.com/HunterTrowel/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Списки обхода можно расширить собственными адресами:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** — домены, которые нужно исключить, например когда сеть присутствует в `ipset-all.txt`, но отдельный домен фильтровать не требуется;
- **`ipset-all.txt`** — IP-адреса и подсети;
- **`ipset-exclude-user.txt`** — IP-адреса и подсети для исключения.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
