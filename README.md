> [!WARNING]

> ### АНТИВИРУСЫ И WInDivert
> Антивирус может отреагировать на WinDivert.  
> Для работы zapret нужен WinDivert - инструмент перехвата и фильтрации сетевого трафика.
> Он может встречаться и в безопасных, и во вредоносных программах, однако сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert потенциально опасными или относит их к хакерским инструментам. В результате файл удаляется и попадает в карантин. Название обнаружения обязательно содержит `WinDivert` либо `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса или отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При грамотной настройке исключений лучше добавить каталог в исключения, но если назначение параметров вам непонятно, рекомендуется отключить детектирование PUA.

## ⚙️ Установка и запуск

1. Активируйте безопасный DNS (Secure DNS).
   * В Chrome включите "Использовать безопасный DNS" и выберите DNS-провайдера, отличного от "Поставщик по умолчанию".
   * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", выберите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, `https://dns.google/dns-query`: провайдер Cloudflare может быть заблокирован.
   * В Windows 11 Secure DNS можно включить непосредственно в настройках системы. Инструкция доступна [здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот вариант рекомендуется.
   * На роутерах Keenetic включите параметр "Транзит запросов". При отключении этой функции настройка и работа Secure DNS на компьютере могут быть нарушены.

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/HunterTrowel/zapret-discord-youtube/releases/latest).

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно пропустить.

4. Распакуйте файлы в путь без кириллицы и специальных символов.

5. Запустите нужный сценарий.
   * Чтобы найти рабочую стратегию, откройте **`service.bat`** и выберите `Run Tests` -> `Standard tests` -> `All configs`.
   * Для запуска стратегии вместе с системой перейдите в **`service.bat`**: `Install Service` -> *подходящая стратегия*.

## ℹ️ Назначение файлов и команд

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вас**.

- [**`service.bat`**](./service.bat) содержит установку автозапуска и дополнительные операции:
  - <ins>**`Install Service`** - добавляет выбранную стратегию в автозапуск через services.msc.</ins>
  - **`Remove Services`** - удаляет стратегию и WinDivert из служб.
  - **`Check Status`** - показывает состояние обхода и служб, включая стратегию автозапуска и WinDivert.
  - **`Game Filter`** - меняет режим обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** - переключает фильтрацию сервисов из `ipset-all.txt`.  
  Режим полезен для диагностики ресурса, который без zapret работает, а с ним перестаёт.  
  В скобках показывается состояние:
    - `none` - адреса не проходят проверку;
    - `loaded` - адрес проверяется на присутствие в списке;
    - `any` - под фильтр попадает любой адрес.
  - **`Auto-Update Check`** - включает или отключает автоматическую проверку обновлений.
  - **`Replace active fakes`** - меняет используемый fake на другой файл из каталога `bin`.
  - **`Update IPSet List`** - загружает актуальный `ipset-all.txt` из репозитория.
  - **`Update Hosts File`** - обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения Discord к голосовому чату**.</ins>
  - **`Check for Updates`** - вручную проверяет наличие обновлений.
  - **`Run Diagnostics`** - ищет распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает неожиданно переставший работать клиент.
  - **`Run Tests`** - запускает проверку стратегий:
    - `Standard tests` - проверяет сайты из `utils/targets.txt`;
    - `DPI checkers` - тестирует DPI у разных провайдеров, включая Cloudflare и Amazon.

## ☑️ Частые вопросы

### После `general*` нет видимого результата

При запуске стратегии отдельным bat-файлом, а не через service, в панели задач должен появиться `winws.exe`, отвечающий за обход. Если процесс не появился, ознакомьтесь с [#522](https://github.com/HunterTrowel/zapret-discord-youtube/issues/522).

### Не нашлась рабочая стратегия

- Откройте командную строку с правами администратора.
- Выполните по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер.

### Не открывается Telegram в браузере

В **`service.bat`** выберите **`Update hosts file`**. Если установленный hosts устарел, программа предложит обновить его вручную:

- скопируйте весь текст из открывшегося блокнота;
- откройте файл `hosts` в созданном каталоге текстовым редактором, запущенным от имени администратора;
- добавьте скопированный текст в конец файла `hosts` либо замените прежний аналогичный блок;
- сохраните изменения и снова проверьте соединение. Если результата нет, убедитесь, что файл действительно сохранился.

#### Работа не гарантируется. Если этот способ не помог, используйте [версию Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/HunterTrowel/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Обнаружение провайдером способно вывести из строя стратегию, которая раньше работала.
> Здесь доступно много вариантов обхода. Если готовые настройки не помогают, создайте новую стратегию на основе одной из них, изменив параметры.
> Описание параметров приведено [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` -> `Run Diagnostics` проверьте наличие ошибок.
- Убедитесь, что адрес ресурса присутствует в списке доменов или IP-адресов.
- Переберите другие варианты, включая **`ALT`** и **`FAKE`**.
- Выполните полную переустановку по инструкции ниже.
- Обратитесь к [#765](https://github.com/HunterTrowel/zapret-discord-youtube/issues/765).

### Полная переустановка или обновление

- Сохраните добавленные вами ресурсы и данные.
- Перезагрузите устройство.
- Откройте `service.bat` -> `Remove Services`.
- Выполните `service.bat` -> `Run Diagnostics`; при наличии ошибок исправьте их и в конце выберите Y.
- Удалите каталог zapret.
- Скачайте свежую версию [со страницы релизов](https://github.com/HunterTrowel/zapret-discord-youtube/releases) с именем `zapret-discord-youtube-...`.
- Нажмите правой кнопкой по архиву, откройте свойства и, если доступен флажок разблокировки, включите его, затем нажмите "Применить" и "ОК".
- Распакуйте архив в новый каталог в корне диска, без пробелов и специальных символов.
- Запускайте разные `general`-скрипты и проверяйте интернет-ресурсы. Если текущая стратегия не работает, закройте программу через значок замка в панели задач и выберите следующую.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service`.

### Игра или приложение не работает при включённом zapret

Проверьте в `service.bat`, что `Game Filter` имеет состояние **`disabled`**, а `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о WinDivert

Инструкция размещена [здесь](https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide).

### Windows 7 требует цифровую подпись драйвера WinDivert

Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert остался среди служб

1. Узнайте имя службы в командной строке Windows, открытой через Win+R -> `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS](#%EF%B8%8F-установка-и-запуск) настроен.
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Перепробуйте остальные стратегии, особенно если раньше доступ работал.
- Дополнительная информация есть в [#251](https://github.com/HunterTrowel/zapret-discord-youtube/discussions/251).

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8F-установка-и-запуск).
- Сначала определите стратегию, на которой открывается сайт YouTube, и запустите её.
- В `service.bat` перейдите в `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, ей можно пользоваться.
- Если сайт тоже недоступен, снова проверьте все стратегии: YouTube и Discord могут работать на разных вариантах.
- См. также [#252](https://github.com/HunterTrowel/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/HunterTrowel/tg-ws-proxy).
- Либо подключите бесплатный MTProto-прокси из интернета.

### Не запускаются игры

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

Попробуйте следующий общий порядок:

- обновите ipset через `service.bat` и включите `Game Filter`;
- если это не помогло, дополнительно включите `ipset any`.

Учтите: режим `ipset any` может нарушить открытие множества сайтов. Не оставляйте его включённым постоянно. Найдите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если проблема сохранится, создайте обсуждение в разделе [Discussions](https://github.com/HunterTrowel/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Вопроса нет в списке

Опишите проблему [здесь](https://github.com/HunterTrowel/zapret-discord-youtube/issues).

## 🗒️ Добавление адресов

Расширить список ресурсов для обхода можно через следующие файлы:

- **`list-general-user.txt`** - домены; поддомены учитываются автоматически;
- **`list-exclude-user.txt`** - домены, которые нужно исключить, например когда IP-сеть присутствует в `ipset-all.txt`, но конкретный домен фильтровать не требуется;
- **`ipset-all.txt`** - IP-адреса и подсети;
- **`ipset-exclude-user.txt`** - IP-адреса и подсети, которые нужно исключить.

Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
